# Проектная работа «Бэкенд WebLarek»

Проект выполнен в рамках практической работы учебного курса **Яндекс.Практикум**, представляет из себя страницу интернет-магазина, в котором представлены товары для веб-разработчиков. В нем можно посмотреть представленный каталог товаров, добавить в корзину и оформить из нее заказ.

Цель работы заключалась: реализовать бэкенд для проекта «WebLarek». 

**Стек технологий:** TypeScript, Mongodb, ODM Mongoose, Node.js.

### В ходе работы выполнены следующие задачи:

:heavy_check_mark:	создана схема и модель сущности товар 

:heavy_check_mark:	настроены контроллеры и роуты для товаров и оформления заказа 

:heavy_check_mark:      раздача картинок с сервера 

:heavy_check_mark:      выполнена централизованная обработка ошибок  

:heavy_check_mark:      валидация данных на уровне получения данных и на уровне схемы   

:heavy_check_mark:      настроено логирование запросов и ошибок приложения  

## Установка и запуск

В директориях:

`web-larek-express/backend/` cоздайте `.env файл` из `.env.example`

`web-larek-express/frontend/` cоздайте `.env файл` из `.env.example`

Установите зависимости в `web-larek-express/backend/`, `web-larek-express/frontend/`

```
npm install
```


### Запуск локально

Установите **MongoDB** скачав дистрибутив с официального сайта или с помощью пакетного менеджера вашей ОС.

Через **MongoDB Compass** создайте:  

`Connection: localhost:27017`  
`DataBase: weblarek`  
`Collection: products` (для наполнения коллекции используйте `web-larek-express/backend/test/product.json`)`  

#### Бэкенд

**MongoDB** должно быть запущено.
Запустите бэкенд:

```
npm run start
```

бэкенд доступен на http://localhost:3000/

#### Фронтенд

Запустите фронтенд:

```
npm run dev
```

приложение доступно на http://localhost:5173/

### Запуск в Docker

Выполните комманду:

```
docker compose up -d
```
При создании контейнеров выполнится скрипт `web-larek-express/_volume/mongo/mongo-init.js`, который создаст БД, коллекцию и наполнит ее нужными данными.  

Также на http://localhost:8081/ доступен контейнер **mongo-express** для ручного взаимодействия с MongoDB.

Приложение доступно на http://localhost/
